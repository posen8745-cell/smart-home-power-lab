# 智慧家庭分路用電監測與錯峰建議｜Wi‑Fi 手機原型 v4

**作者：基隆私立二信高中・普通科數理班・張博程**  
**作品階段：高中電機自主學習／可操作軟體原型／未上市**

> **重要安全界線**：程式目前只有虛構配電箱、`mock_panel.json` 示範數據與 Wi‑Fi 局域網手機網頁。**沒有接線、沒有連上家中配電箱、沒有經校正的電力感測器，也沒有任何對家電、開關或斷路器的實際控制功能。** 警示門檻與模擬跳脫不等於真實斷路器保護。任何實際配電箱設備的選型、施工、測試與維護，應由符合資格的專業人員負責。

## 一、作品動機：家庭用電問題

家裡只有總用電帳單時，很難看出哪一條分路或哪些同時使用的電器造成瞬間負載偏高。即使住戶知道客廳、廚房或房間正在使用哪些設備，也未必清楚各區實際接在哪一個迴路上。我希望先練習設計「**分路資料 → 用電排序 → 高負載提醒 → 錯峰建議 → 手機查看**」的完整資訊流程，未來研究可否做成協助家庭用電管理的商品。

**這不是一款已完成的智慧電箱產品。** 現階段以軟體模擬驗證介面與演算法；如果要實際使用，仍需合格的分路計量設備、專業配線核對、資安設計、設備校正與安全驗證。

## 二、現實問題與本次修正（v4）

| 現實問題 | v4 的處理方式 | 尚未完成的部分 |
|---|---|---|
| 分路不等於房間 | JSON 使用「廚房／浴室共用」等名稱，明確標示**未現地核對** | 實際配電圖、分路辨識與標籤確認 |

| 錯峰不一定省電 | 明確區分「降低同時尖峰」與「降低總電能」 | 實際用戶行為、費率與節能效果實證 |

| 手機顯示的數值可能不是即時 | 時間戳超過 120 秒、時區缺失或外部資料缺漏時提示過期／無效 | 真實設備的時鐘同步與故障告警 |
| 商品需要安全與隱私 | 不提供任何實體斷電介面，Wi‑Fi 僅可信任區域網課堂展示 | TLS、設備身分識別、安全更新、法規審驗 |

## 五、使用方法

解壓縮全部檔案至同一資料夾，電腦與手機連接同一個可信任 Wi‑Fi。

```sh
python3 gateway.py
```

Windows 可以依安裝情況使用 `py gateway.py`。終端機會顯示手機瀏覽網址（例如 `http://192.168.1.10:8765/monitor.html`）和本次啟動的六位示範碼；在手機 Safari／Chrome 輸入該網址及示範碼即可。

手機有「一般用電」「高功率同時使用」「錯峰後」「跨區用電」四種示範情境。可以比較分路排名、瞬間負載和錯峰建議。按「**切換離線 JSON 示範**」，會明確顯示不是 Wi‑Fi 實時讀值；Wi‑Fi 中斷時不會自動切回看似正常的模擬資料。

完成展示後，在電腦終端機按 `Ctrl+C` 停止伺服器。**不要將本示範服務進行路由器 Port Forwarding、公開到網際網路或用於真實監測告警。** 六位碼＋HTTP 不具備正式產品所需的安全性。

## 六、功率、電流與度數的原理

- **瞬時功率（W）**：目前負載大約消耗多少瓦特，不是月耗電。
- **示範電流（A）**：`I ≈ P / (V × PF)`。此處採固定額定電壓、簡化功率因數；**不是感測器直接量到的電流，也不能用來推估斷路器確切跳脫時機**。
- **累計電能（kWh）**：`E = ∑(P × Δt) / 3,600,000`，P 單位 W、Δt 單位秒。網關僅將**連續且有效的相鄰樣本**加總，本次程式結束就重置，無法代表一天或一個月完整度數。
- **示範負載占比**：`P / (V × PF × 示範額定A)`。80% 提醒、100% 超限僅是自行設定的教學演算法，**非標準保護曲線／法定危險門檻**。

**計算例子**：1,200W 吹風機連續使用 30 分鐘約用掉 `1,200×0.5/1,000=0.6 kWh`。即使改到不同時段使用相同時間，仍約是 0.6 kWh；「錯峰」主要是避免與其他電器形成同時用電尖峰。

**注意 110／220V**：JSON 可以個別設定分路電壓；如果混合不同電壓，系統不再把所有分路電流直接加總成「總開關電流」，也不使用單一電壓算出看似精確的總電箱容量。正式量測須配合配電形式，由專業人員解讀電壓、電流和有功功率。

## 七、示範情境與分路

| 虛構分路 | 名稱 | 假設電壓 | 容量（教學） |
|---|---|---:|---:|
| A | 廚房／浴室共用（示範） | 110V | 15A |
| B | 客廳／走道照明（示範） | 110V | 10A |
| C | 書房／臥室設備（示範） | 110V | 15A |

| 情境 | A | B | C | 當下總功率 |
|---|---:|---:|---:|---:|
| 一般用電 | 0W | 67W | 440W | 507W |
| 高功率同時使用 | 1,900W | 0W | 0W | 1,900W（A 超示範門檻） |
| 錯峰示範後 | 700W | 0W | 0W | 700W（延後 1,200W 吹風機） |
| 跨區＋錯峰後 | 700W | 67W | 440W | 1,207W |

以上都不是現場設備規格，**不可拿來決定家中斷路器大小、配線或實際負載是否安全**。

## 八、外部 JSON 資料介面（未驗證來源）

```sh
python3 gateway.py --telemetry telemetry.example.json
```

格式如下（應把時間改成**帶時區的當前時間**，否則會標成「資料過期」）：

```json
{
  "timestamp": "2026-11-07T08:00:00+08:00",
  "source": "EXAMPLE_NOT_A_REAL_METER",
  "zones": { "A": 920, "B": 210, "C": 480 }
}
```

`zones` 的 W 值必須涵蓋所有分路；缺一條、檔案讀取失敗或格式錯誤，就顯示**外部資料不可用**，不自動替換成正常的虛構讀值。來源時間超過 120 秒、無時區或時鐘不正確，顯示過期狀態。**本介面不包含真實感測器驅動**；未來只能由經評估的合格量測裝置透過安全、隔離的資料路徑輸入。

## 十、已做的測試、限制與下一階段

使用 `python3 -m unittest -v test_gateway.py` 測試：預設場景、1,900W 示範超限、700W 錯峰、跨區合計、外部資料正常／過期／缺欄、110／220V 混合計算、網關讀值中斷不冒充模擬資料，以及連續樣本 kWh 積分。這是**程式層級測試**，不是精度校驗或真實電箱測試。

本次學習到：先確定資料來源是否可靠，再談自動建議；知道分路電功率、瞬時負載、累計電能三者不同；也了解到電氣安全保護不能依賴沒有硬體驗證的軟體畫面。下一階段可以先在老師指導下進行隔離的低電壓教學量測，再與專業廠商合作評估合格分路電表及資料連線。
