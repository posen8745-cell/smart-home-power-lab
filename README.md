# 智慧家庭用電監測與過載警示模擬系統

**作品類型：高中自主學習｜電機工程探索｜互動網頁模擬**  
**作者：基隆私立二信高中・普通科數理班・張博程**  
**作品狀態：已完成純網頁模擬；沒有連接真實電表、插座、電流感測器或斷路器**

> **重要提醒：** 這是電學與控制邏輯的**教學用模型**，不是家庭配電安全檢查工具。所有電器瓦數、電流上限、警戒燈號、過載跳脫與費用都屬示範；不可據此推斷真實插座或電線是否安全，也不可用於施工、配線或保護設備選型。

## 一、作品介紹與自主學習動機

之前的作品以交通號誌控制、坡地雨量模擬及資料查詢為主。這次我想進一步接觸**電機工程的電力與控制概念**，不只是把資料顯示在網頁上，而是讓使用者自行設定負載，再觀察不同操作對電流、功率及耗電量的影響。

例如：如果同時開啟電鍋及吹風機，兩者耗電功率相加，可能超過某一條**假設回路**的容量。那麼能否設計簡單的控制規則，先暫停可延後使用的電器，降低模擬負載？我以這個問題為出發點，設計了可在瀏覽器操作的用電模擬系統。

這是一份**高中電機探索的自主學習作品**，不宣稱已完成硬體實作或現場量測。

## 二、自主學習目標

1. 理解電壓（V）、電流（A）、功率（W）及電能（kWh）的關係。
2. 練習由電器功率與設定電壓估算電流，顯示虛擬回路的負載比例。
3. 建立「正常、接近上限、超出上限」的狀態顯示邏輯。
4. 設計一個簡單的**負載管理規則**，比較「沒有管理」及「優先暫停可延後負載」的差異。
5. 模擬 24 小時用電資料，將結果畫成曲線並匯出 CSV 以利分析。
6. 分辨網頁估算與真實電氣量測之間的差別。

## 四、核心電學原理與示範參數

本系統採取**固定電壓與功率因數為 1 的簡化假設**，所以電流估算式為：

```text
I = P ÷ V
I：示範電流（A）
P：電器總功率（W）
V：示範電壓（V）
```

以 `110 V` 與 `15 A` 的教學設定為例：

```text
設定上限功率 = 110 × 15 = 1,650 W
提醒門檻 = 1,650 × 80% = 1,320 W
```

其中 **15 A 與 80% 是本作品自行選用的演示參數**，不是所有住宅回路均可適用的安全值，也不代表實際斷路器會在超限時立即跳脫。臺灣的家庭電力可使用 110 V、220 V，實際回路與電器應依電氣專業規格處理；本作品只示範單一假設 110 V 回路。真實交流負載可能受到功率因數、啟動電流、線路條件及負載變化影響。

模擬用電量：

```text
E（kWh）= P（W） × t（小時） ÷ 1000
例如：700 W 模擬使用 15 分鐘
E = 700 × 0.25 ÷ 1000 = 0.175 kWh（度）
```

**注意：** 真實用電功率可能隨時間改變；本作品假設每台電器在每個步進期間功率固定。示範電費為 `kWh × 自訂每度單價`，未納入台電累進、季節、基本費用及其他計費條件。

## 五、兩組對照實驗

### 實驗 A：沒有負載管理

1. 點「**實驗 A：不管理負載**」。
2. 程式設定只有電鍋 700 W、吹風機 1200 W 同時開啟，並關閉智慧負載管理。
3. 總要求功率為 `700 + 1200 = 1900 W`。
4. 估算電流為 `1900 ÷ 110 ≈ 17.27 A`，超出假設的 `15 A` 上限。
5. 網頁立即進入**模擬跳脫**，顯示供電功率 0 W。

> 本操作不會真的讓任何家電斷電。此處的「跳脫」只是簡化後的程式狀態。

### 實驗 B：加入簡單的負載管理

1. 點「**實驗 B：智慧管理負載**」。
2. 同樣將兩台電器總要求功率設為 1900 W，但啟用智慧管理。
3. 由於吹風機被設定為「可延後」，程式優先暫停其 1200 W 示範負載。
4. 剩餘供電功率為 700 W，估算電流 `700 ÷ 110 ≈ 6.36 A`。
5. 再按「前進 15 分鐘」，可看到累積電量增加 `0.175 kWh`。

這不是自動判斷實際家庭哪個電器可以安全斷電；優先順序完全由使用者在教學頁面自行指定。真正的設備控制須另外考慮使用安全及各裝置限制。

## 六、操作方式

1. 使用瀏覽器開啟 `index.html` 或 GitHub Pages 網址。
2. 在「電器負載控制」區切換電器開關、輸入瓦數和管理優先順序。
3. 觀察上方的功率、電流、累積用電與示範電費。
4. 依需要修改假設回路電流上限（預設 15 A）。
5. 可開啟智慧負載管理，比較模擬超限前後的供電結果。
6. 使用「前進 15 分鐘」或「播放模擬」產生最多 96 筆模擬資料。
7. 查看 24 小時折線圖、事件紀錄，並按「下載 CSV 實驗紀錄」輸出。
8. 建議依序操作實驗 A、B；每次操作案例會清除先前模擬紀錄，避免混合兩組資料。

**模擬時間與真實時間不同：** 播放模式每現實 1 秒表示模擬 15 分鐘；當分頁切到背景時程式會自動暫停。沒有真實 24 小時監測、通知或雲端儲存。

## 七、程式設計與電機工程的關係

| 電機相關概念 | 在作品中的呈現 | 目前程度 |
| --- | --- | --- |
| 電學計算 | 功率、電流、電能估算 | 網頁公式模型 |
| 電力負載分析 | 多個電器的總瓦數與上限比較 | 假設單一回路 |
| 保護與狀態機 | 正常、提醒、模擬跳脫、模擬復歸 | 軟體狀態控制 |
| 控制策略 | 依優先等級自動暫停部分負載 | 規則式控制，非 AI |
| 時序資料 | 每 15 分鐘一筆功率及累積電能 | 虛擬計時與資料處理 |
| 人機介面 | 可操作的電器開關、KPI、事件及折線圖 | HTML、CSS、JavaScript |
| 感測與控制硬體 | 以實測數據取代假設值、控制實體負載 | **尚未實作** |

這份作品的重點是把「電學公式」轉換成可測試、可對照的控制規則。**它比純資料查詢更直接連結電機工程，但仍是軟體教學專題，而不是硬體實驗成果。**

## 八、部署到 GitHub Pages

此版本沒有任何外部套件、伺服器、資料庫或 API 金鑰；下載後以瀏覽器直接開啟 `index.html` 也能執行。

```text
smart-home-power-lab/
├── index.html    # 完整網頁、樣式與 JavaScript
└── README.md     # 專題與自主學習說明
```

部署方法：

1. 在 GitHub 建立一個**新的**儲存庫（例如 `smart-home-power-lab`）。**不要覆蓋原本學習歷程網站的 `index.html`。**
2. 將本專案的 `index.html`、`README.md` 放在儲存庫根目錄。
3. 在 Settings → Pages 選擇 `Deploy from a branch`，Branch 選 `main`、Folder 選 `/(root)`。
4. 發布成功後，網址通常是 `https://你的帳號.github.io/smart-home-power-lab/`，以 GitHub 顯示的正式網址為準。
5. 在原本的學習歷程網站新增作品連結，並將其標示為「電機自主學習｜純網頁模擬」。

## 十、限制、延伸方向與參考資料

**現階段限制：**

- 只有虛擬電器及固定 110 V 教學回路，沒有真實電表、電流互感器或實體負載。
- 將功率因數視為 1，沒有建模電感性負載的實際交流電流、啟動瞬間、電壓下降與諧波。
- 「80% 提醒」與「超過設定值就跳脫」都是**示範策略**，不是通用法規或真實保護裝置的動作曲線。
- 沒有台電官方即時電價、正式用電計費模型或家庭整戶配電模型。
- 不可用來判斷居家配線容量、延長線安全性、漏電或短路。

**若要延伸成硬體自主學習：** 可以在教師或專業人員指導下，**先從隔離的低電壓直流**電路（如低電壓教學電源、LED 與合適的電流感測模組）研究電流量測、Arduino／ESP32 讀值與資料記錄；在學會隔離、防護與量測原理前，**不要自行拆裝、接觸或改造 110/220 V 市電配線**。未來也可比較電阻性與非電阻性負載，加入真正的負載量測與控制回饋。
