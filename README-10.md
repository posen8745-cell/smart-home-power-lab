# 餐廳用電小實驗：先等等，再開下一台

基隆私立二信高中・普通科數理班・張博程的自主學習作品。

## 為什麼想做

家中一樓餐廳使用高功率電器時，常會發生跳電。餐廳有氣炸燒烤爐、微波爐、電鍋、IH 飯鍋和飲水機。我因此想到：如果家人想再開另一台電器，能不能讓程式先算一下目前的負載，超過設定上限就請它等一下？

**想法與功能需求由我提出，程式和介面由 AI 協助完成。我負責操作、觀察結果、提出問題，再請 AI 協助修正。** 目前不是全部由我獨立寫出的程式，我也還在學習裡面的計算與控制方式。

## 這次想讓人看懂什麼

畫面改成三個動作，先讓人看懂「程式根據當下負載做決定」。

1. **先開氣炸燒烤爐**：它開始使用，假設功率是 1500W。
2. **這時想再開微波爐**：微波爐假設是 1100W，兩台合計 2600W，超過這個例子設定的 1650W 上限。程式保留正在使用的氣炸燒烤爐，讓後提出要求的微波爐先等待。
3. **結束氣炸燒烤爐**：程式重新檢查，空間足夠後，微波爐就自動接續開始。

按「重新示範」可以回到最初狀態與預設瓦數。不必先操作圖表、播放時間或計算度數。

## 也可以自己試五項電器

| 電器 | 假設輸入功率 |
|---|---:|
| 氣炸燒烤爐 | 1500W |
| 微波爐 | 1100W |
| 電鍋 | 700W |
| IH 飯鍋 | 1200W |
| 飲水機（加熱階段） | 700W |

這些瓦數是可修改的示範值，不是家中實測。微波爐要看輸入功率，不能直接把微波輸出功率當成耗電功率。飲水機只示範加熱階段，沒有模擬待機、保溫或間歇加熱。

- 按「我要使用」：程式先檢查目前使用中的功率與新增需求。
- 放得下就顯示「使用中」；放不下就顯示「等待中」。
- 按「結束使用」：釋出空間，再檢查等待中的電器。
- 按「取消等待」：取消這次要求，也會重新檢查後續等待項目。

正在使用的電器不會因為另一台提出要求而被中途關閉。等待依提出要求的順序安排，前面的放得下才開始。只要合計沒有超過上限，多台可以一起用，例如電鍋 700W 加飲水機加熱 700W，共 1400W，就能同時開始。

這版沒有固定讓每台排隊使用 15 分鐘，也沒有自動判斷食物煮熟。使用者按「結束使用」，只是模擬前一台已經用完，讓人觀察程式重新檢查的結果。

若單一電器的假設瓦數就超過設定上限，即使其他電器都結束，它仍會等待。頁面會說明原因，可以取消等待後再修改示範值。

## 程式怎麼判斷

```text
目前使用功率 + 新電器功率 ≤ 示範上限：可以開始
目前使用功率 + 新電器功率 > 示範上限：先等待
```

預設先假設同接一條 110V、15A 的分路，上限為 `110 × 15 = 1650W`，功率因數假設為 1。**家中實際迴路和跳電原因尚未量測確認；同在餐廳不代表一定同接一條分路。** 這個設定不能用來預測真實斷路器何時跳脫。

## 延伸計算與操作紀錄

主畫面只看「誰在用、誰在等、為什麼」。想深入了解時，再展開下方區塊：

- 「想知道程式怎麼算？」：查看加總、上限和等待規則。
- 「延伸：調整假設值、計算度數與下載紀錄」：修改瓦數或分路額定電流，按目前狀態試算 15 分鐘用電，或下載操作紀錄 CSV。

有電器使用中或等待中時，假設值會鎖定，避免把運作中的設定突然改掉。全部結束並取消等待後才能調整。調整後使用五項電器的自由操作按鈕；按「重新示範」會恢復預設。

延伸的度數按鈕只計算目前功率持續 15 分鐘的用電量，不會讓任何電器自動結束。公式是 `E = P × t ÷ 1000`，P 為瓦、t 為小時。錯開使用主要降低同時用電的功率，不會自動減少完成相同使用量的度數。

CSV 記錄每次動作、使用中的電器、等待中的電器、目前使用功率與示範上限。紀錄只保留在這次開啟的頁面，沒有上傳到伺服器。

## 更新檔案

用本次的 `index.html` 與 `README.md` 覆蓋 GitHub 同名檔案。首頁檔名必須剛好是 `index.html`。

這個簡化首頁已內建五項電器與預設參數，**不需要讀取 `mock_panel.json`**。原有 JSON、`monitor.html`、`gateway.py` 等檔案可以保留；原手機頁仍是不同的獨立情境，不會同步這個首頁的使用與等待狀態。原有 Wi-Fi 原型需另外在電腦執行 `python3 gateway.py`，GitHub Pages 不會執行 Python。

這次將原本較複雜的固定排程、跳脫比較和 24 小時曲線，改成「提出要求 → 檢查 → 等待 → 空間釋出後接續」。希望高中生第一次操作就能看出程式幫了什麼忙。

## 目前的範圍

這是純網頁的概念模擬，沒有連接電表、感測器、配電箱或真實家電。目前不能幫家中實際防止跳電，也沒有驗證實際節能效果。真實家電也不一定能透過簡單的斷電、送電方式開始或恢復工作。

我希望先把自己的想法說清楚，再逐步學習量測、資料讀取與控制之間的差別。頁面中的數字不能用來判斷家中配線、插座或斷路器是否安全。
